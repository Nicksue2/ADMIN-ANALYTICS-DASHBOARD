# ADMIN ANALYTICS DASHBOARD

## Project Overview

This repository contains the source code for the **Admin Analytics Dashboard**, a web-based application developed as the final requirement for **BSIT** (Data Structures and Algorithms and Elective 1: Business Intelligence).

The dashboard is designed to showcase the practical application of core computer science concepts, specifically in visualizing and analyzing data to support informed decision-making (Business Intelligence).

------------------------------------

## Key Project Objectives

This project fulfills the following academic and technical requirements:

1.  **Business Intelligence (BI) Implementation:** To provide users with a clear, interactive visual representation of key performance indicators (KPIs) relevant to sales...etc.
2.  **Data Structure Application:** To utilize fundamental data structures (e.g., arrays, linked lists, hash tables) in the backend to efficiently process, store, and retrieve data for analysis and display.
3.  **Algorithmic Efficiency:** To employ effective algorithms (e.g., sorting, searching) to ensure the fast loading and reliable performance of data visualizations.
4.  **Full-Stack Development:** To integrate backend logic (PHP/MySQL) with modern frontend technologies (HTML, CSS, JS) to deliver a seamless user experience.

## Getting Started (Local Setup)

Follow these steps to set up and run the project locally using XAMPP:

1.  **Prerequisites:** Ensure **XAMPP** (or equivalent WAMP/MAMP stack) and **Git** are installed on your system.
2.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/Nicksue2/ADMIN-ANALYTICS-DASHBOARD.git](https://github.com/Nicksue2/ADMIN-ANALYTICS-DASHBOARD.git)
    ```
3.  **Placement:** Copy the cloned `ADMIN-ANALYTICS-DASHBOARD` folder into your XAMPP's web root (`htdocs`).
4.  **Database Setup:**
    * Start **Apache** and **MySQL** from the XAMPP Control Panel.
    * Import the necessary database schema and data into your MySQL server. (The SQL file should be included in the repo, or provide instructions here).
5.  **Access:** Open your web browser and navigate to the project's entry point:
    ```
    http://localhost/ADMIN-ANALYTICS-DASHBOARD/www.php 
    ```
    *(Adjust the filename if your main entry point is `index.php` or another file.)*
